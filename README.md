# 나인 모리스 (Nine Men's Morris)

한 PC에서 두 사람이 번갈아 두거나, 컴퓨터와 대전할 수 있는 웹 보드게임입니다.

## 실행 방법

- `index.html`을 내려받아 브라우저로 열면 바로 플레이할 수 있습니다. (설치·서버 불필요)
- GitHub Pages: 저장소 **Settings → Pages**에서 Source를 `main` 브랜치로 지정하면
  `https://haneulryu.github.io/nine-mens-morris/` 에서 접속할 수 있습니다.

## 규칙

- **놓기:** 흰색부터 번갈아 9개씩 빈 점에 말을 놓습니다.
- **이동:** 모두 놓은 뒤에는 선을 따라 인접한 빈 점으로 한 칸 이동합니다.
- **밀:** 한 줄에 내 말 3개를 만들면 상대 말 1개를 제거합니다. 밀에 속한 말은 상대 말이 전부 밀에 속해 있을 때만 제거할 수 있습니다.
- **플라잉:** 말이 3개만 남으면 아무 빈 점으로나 이동할 수 있습니다.
- **승리:** 상대 말이 2개 이하가 되거나, 상대가 움직일 수 없으면 승리합니다.
- **무승부:** 이동 단계에서 50수 동안 밀이 만들어지지 않거나, 무승부 제안을 상대가 수락하면 무승부입니다.

## 기능

- **게임 모드:** 2인 대전(한 PC에서 번갈아 두기) / 컴퓨터 대전
- **컴퓨터 난이도:** 쉬움 · 보통 · 어려움
- **선공/후공 선택:** 컴퓨터 대전 시 흰색(선공) 또는 검은색(후공) 선택
- **전체 화면:** 게임판을 화면 가득 키워서 플레이 (Esc 또는 [전체 화면 종료]로 복귀)
- **손에 든 말 표시:** 게임판 위·아래에 9개씩 놓여 있다가 놓을 때마다 하나씩 사라짐
- **마지막으로 잡힌 자리:** 빨간 ✕와 흐린 말로 표시
- 이동 가능 칸 / 제거 가능 말 표시, 직전 수와 완성된 밀 강조
- 한 수 무르기(컴퓨터 대전에서는 내 차례까지 되돌림), 무승부 제안, 새 게임
